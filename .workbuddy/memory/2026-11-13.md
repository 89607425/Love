# 2026-11-13

## 留言板两个 bug 修复（love 项目）

- **新消息在最上面**：`db.ts` 的 `getMessages` 用 `ORDER BY created_at DESC`，前端照渲染。改成 `ASC`。该函数只有 messages API 一个调用方，改动安全。
- **聊天区滚不动**：flexbox 经典坑——`flex-1 overflow-y-auto` 的子项默认 `min-height: auto`，内容一多被撑开而不是收缩，overflow 失效，外层 `overflow-hidden` 直接裁掉内容。加 `min-h-0` 解决。
- 顺手重构：输入栏从 `fixed bottom-16`（配 `pb-44` hack）改为正常文档流的 `shrink-0` 子项，外层 `pb-16` 给底部导航留位。高度链条完整，iOS 键盘弹起行为也更稳。
- 顺带修的两个隐患：
  - GET /api/messages 有 60s 缓存，发送后 refetch 可能拿旧数据 → `fetchMessages` 加 `cache: "no-store"`，且 `handleSend` 直接把 POST 返回的新消息 append 进 state（带 id 去重）。
  - 删除按钮 `group-hover` 在触屏上永远不可见 → 改为移动端常显（弱化 opacity-40）、桌面端 hover 显示（`sm:opacity-0 sm:group-hover:opacity-100`）。
- 验证：tsc 干净、build 通过、dev 页面 200 且新布局类名在 HTML 里。本地 `/api/messages` 500 是因为没有 DATABASE_URL（数据在 Vercel Neon），与改动无关。
- 环境注意：3000 端口常被一个旧进程占用（本次 PID 88614），next dev 会自动换 3001。
